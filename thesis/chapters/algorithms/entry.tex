\chapter{Algorithms}

% introduction
In order to test if the proposed exoskeleton can aid in the training of the robots, a simulated environment with a task has been created in which an UR5 robot arm will have to pick-and-place virtual balls of varying stiffness into apropriate boxes. This task will be performed using three different methods: a
classical approach, where there robot trajectory is generated from points, a reinforcement learning approach, where the robot aims to perform a task by trial and error, while learning from the past mistakes and trying to maximize some reward metric specified by the user and lastly, inverse reinforcement learning, where the rewards are learned from human demonstration instead of being specified before the reinforcement learning model is trained.
