\subsection{Classical Approach to Control}

In 1961, Unimate, the first industrial robot, which worked on General Motors assembly line, was created. The Unimate was a hydraulically operated 5 degrees of freedom arm that performed pick-and-place tasks. The robot could be programmed by manually moving a robot arm to the a desired position and recording the position. Then the robot could replay the movement by moving to the same position. This resulted in the first of it's kind point-to-point movement which is still a standard feature in many robotic arms today. 
Such control method is quite simple, but it does require manual programming, meaning it is most suited for simple, repetitive tasks in well known environments. Besides that, the point-to-point movement has two obvious disadvantages. Firsty, the robot movement does not appear smooth, secondly, there must be no obstales between the points. These problems have been adressed in modern robotic control. The most simple way to move between two points is use linear interpolation. Similarly, orientation can be interpolated, depending on the representation chosen. For example, if orientation is represented as quaternions, a spherical linear interpolation (SLERP) can be used. This is because quaternion is a rotation representation on 4D unit sphere and in order to move between two points a sphere, the movement should be done on a following a geodesic. In theory linear interpolation results in constant velocity motion, but in practice this means that at the beginning of the motion robot will need an infinite acceleration to achieve desired velocity instantly and at the end of the movement, it will need infinite deacceleration to stop immediately. Objects with mass resist changes in motion due to inertia. The higher the object's mass is, the more force will be needed to accelerate it. The resistance to rotation also depends on the shape of the object, which is described by the moment of inertia. As robot is a system constrained by physical limitations, it will not experience infinite acceleration, but the motors will likely apply the maximum torque they are capable of during the brief moments at the beginning and the end of the motion. This increases wear and tear of the motor and other components, leading to the decreased lifespan of the robot. This issue can be mitigated by using a parabolic trajectory instead. Assuming the start velocity of zero and end velocity of zero, the parabolic trajectory will have a velocity profile that linearly increases until it reaches the half point of the trajectory and linearly decreases until it reaches zero again at the end of the trajectory. Consequently, the acceleration during first and second half of the movement will have much lower maximum value and will be constant, non-zero during majority of the motion. This leads to least wear and tear, but also slower movement. A balance between trajectory duration and maximum acceleration can be achieved by merging these two methods. Linear trajectories with parabolic blends have a linear part in the middle and paranolic at the start end end of the interpolation.

\bigskip \noindent
When moving between two points, it is not always clear if the robot will be able to move between then without collision. This is especially true with high degree of freedoom robotic arms as even if the path for the end effector is clear, other robot parts may be in collision due to the configuration of the robot. It is a difficult problem to address efficiently due to high dimentionality of the problem. Many modern robotics incorporate Rapidly-exploring Random Tree (RRT) or RRT* into their path planning algorithms to address this problem. RRT explores robot's configuration space, which is a high dimentional space that represent every possible configuration the robot can be in. C-Space can be divided into two sets, C-Free a space with valid robot configurations and C-Obs a space where robot configuration would be in a collision. 

\begin{gather*}
  C = C_{\text{free}} \cup C_{\text{obs}} \\
  C_{\text{free}} \cap C_{\text{obs}} = \emptyset
\end{gather*}

\noindent
RRT can find a collision free path between the two configurations in C-Free space if one exists. The algorithm builds a tree like structure by selecting a random point in a C-Free space, connecting it to the closest node in a tree (which the initial configuration during the first iteration), and growing a branch from that tree towards the random point until it or maximum distance is reached. That will be the new location for the node to be added into the tree if the path between the node and the closest points in the tree is obstacle free. Then a new random point in a C-Free space is selected and this process continues until a tree grows large enough so a path that connects the two points in configuration space is found. This method however does not yield shortest path, RRT* addresses this issue by doing additional processing before placing a node in a tree. Within a specified search radius around the new point, RRT* checks if the nodes can be reconnected in a way that yields a shorter path. It has been proved that when the time goes to infinity, RRT* will yield the shortest path between two points by continuously rewiring the tree. 

\bigskip \noindent
The linear interpolation between points with or without the use of parabolic blends, results in a robot moving in a straight line between the points. A more efficient and smooth path can be achieved by using splines. Splines ensure a smooth transition between path segments, avoids abrupt changes in velocity and acceration and minimizes jerk. An easy way to implement splines in a path with many points is to use B-splines. This approach is recommended only for the parts in the trajectory that do not need to go through the point exactly, as B-splines are just an approximation of the path, unlike interpolation methods that would go exactly through the point. B-splines are implemented by dividing each segment between points to the thirds and connecting a second third of the first segment to the first third of the second segment with a line. The center of this line will act as an anchor point for fitting a Bezier curve. The B-splines are amazing not only because they are easy to implement, but because they have $C^2$ continuity and local control. Local control means that moving a single point in the trajectory will affect only that local portion of the trajectory, keeping the rest of the trajectory unaffected. $C^2$ continuity (second-order continuity) ensures that the position, velocity and acceleration in the trajectory are smooth. $C^0$ position continuity ensures that the end of one segment matches the start of another. $C^1$ velocity continuity ensures that the first derivatives at the end of the one segment matches the start of another. And $C^2$ acceleration continuity ensures that the second derivative matches at the junction points between the segments. It is possible to achieve even higher order continuity, for example quintic splines can achieve a $C^3$ jerk continuity or even higher if higher degree polynomial is used to interpolate between the points. Quintic splines also go through the points unlike the B-splines. This could be desireable in cases where the points are defined manually. Quintic splines do come with several disadvantages, such as, lack of local control and computational complexity, so the choice of splines used would depend on the use case scenario.

\subsection{Neural Networks}
Neural network is a mathematical model inspired by biological neural network - the human brain. Neural networks are used in machine learning to achieve tasks that would be difficult or impossible by writing an algorithm for the task manually. The feedforward neural network was the first type of the neural network. The information in such a network only flows forward from input to the output, which is very suitable for classification tasks. This type of network is is divided into one dimentional layers consisting of one or more neurons, input layer, one or more hidden layers and an output layer. A neuron can be imagined as a place where a single, usually floating point value is stored. A simple and common approach to connect these layers is to use full connections, where each neuron is connected to every neuron in the previous layer. This is not a problem for small networks, but modern networks can have millions of neurons, in such cases techniques where weak connections are cut are implemented to optimize the networks. The value that the neuron receives is calculated by multiplying the value of the previous neuron by the strength of the connection (weight) and addition of a bias, repeating this for all connections and summing these values. As the neuron multiplication by a weight and addition of a bias is a linear function, the neurons need an additional activation function in order to learn non-linear patterns from data. A common and popular activation function is sigmoid $f(x) = \frac{1}{1 + e^{-x}}$, which also clamps the neuron values between -1 and 1. In big networks however sigmoid adds a lot of additional computation, often ReLU is prefered. It is calculated simply as $f(x) = max(0, x)$. Turns out clamping negative values is enough to provide the desired nonlinearity to the network. ReLU however sometimes presents another problem, if the network is poorly initialized with a lot of negative weights and biases, the learning rate is too high or the data often leads negative neuron activations, the neurons stop learning. This is because after negative neuron value passes through the ReLU function it becomes zero. This is called a dying ReLU problem where too many neurons output zero for all inputs, effectively making them inactive and that prevents them from learning. Leaky ReLU addresses this problem, instead of clamping negative values to zero, they are multiplied by a small constant e.g. $\alpha=0.01$, this neurons from dying. For multi-class classification problem, the logits (raw outputs of the last layer before applying the activation function) are passed through a softmax function $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$, this outputs the probabilities of input beloging to each class, the highest probability is often choosen as a network prediction. The sum of probabilities of input belonging to each class is 1. The data for multi-class clasification is usually one-hot encoded, where the probability of it belonging to the true class is 1 and 0 for the rest. The loss for such problem is calulated using cross-entropy

\[
\mathcal{L} = - \sum_{i} y_i \log(\hat{y}_i)
\]

\noindent
where:  
\begin{itemize}
    \item \( y_i \) is the true label (usually one-hot encoded, meaning one class is labeled as 1, others as 0)
    \item \( \hat{y}_i \)  is the predicted probability for class i from softmax
\end{itemize}


\noindent
The cross-entropy measures the difference between two probability distributions, leading to stronger gradiens than using mean square error. For one-hot encoded dataset, the cross entropy simplifies to $\mathcal{L} = - \log(\hat{y}_{c})$ where $\hat{y}_c$ is the predicted probability of the true class. The goal of neural network training process is to minimize this loss. This is done through a process called backpropagation. The weights and biases need to be adjusted in a way that leads to lower loss. In order to know how the changes in weights and biases affect the loss a gradient can be used. During the backpropagation the gradiens are calculated for each weight and bias by the use of gradient chain rule. This way a simple way to minimize the loss is achieved, simply taking a step for each weight and bias in the negative gradient direction will result in lower loss until either a local or global minima is reached. Often when then network is big and there is a lot of data, it is unpractical to use all of the data for each pass as it is too resource intensive, often the data is split into smaller batches before being passed through the network. Another way a neural network training process is sped up is instead of using the vanilla gradient descent, a modern optimizer like adam is often employed. Adam (Adaptive Momentum Estimation) improves the gradient descent with two key ideas. Firstly, it incorporates momentum by using the mean of past gradients. This helps optimizer move in a constant direction and to reduce oscilations. Secondly, it optimizes the step size for each parameter individually based on past updates. This results in faster convergence, less sensitivity to noisy gradients (which can occur in mini-batch training) and less sensitivity to hyperparameter tuning.
