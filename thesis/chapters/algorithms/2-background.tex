\section{Background}

\subsection{Classical Approach to Control}

In 1961, Unimate, the first industrial robot, which worked on General Motors assembly line, was created. The Unimate was a hydraulically operated 5 degrees of freedom arm that performed pick-and-place tasks. The robot could be programmed by manually moving a robot arm to the a desired position and recording the position. Then the robot could replay the movement by moving to the same position. This resulted in the first of it's kind point-to-point movement which is still a standard feature in many robotic arms today. 
Such control method is quite simple, but it does require manual programming, meaning it is most suited for simple, repetitive tasks in well known environments. Besides that, the point-to-point movement has two obvious disadvantages. Firsty, the robot movement does not appear smooth, secondly, there must be no obstales between the points. These problems have been adressed in modern robotic control. The most simple way to move between two points is use linear interpolation. Similarly, orientation can be interpolated, depending on the representation chosen. For example, if orientation is represented as quaternions, a spherical linear interpolation (SLERP) \cite{shoemake1985animating} can be used. This is because quaternion is a rotation representation on 4D unit sphere and in order to move between two points a sphere, the movement should be done on a following a geodesic. In theory linear interpolation results in constant velocity motion, but in practice this means that at the beginning of the motion robot will need an infinite acceleration to achieve desired velocity instantly and at the end of the movement, it will need infinite deacceleration to stop immediately. Objects with mass resist changes in motion due to inertia. The higher the object's mass is, the more force will be needed to accelerate it. The resistance to rotation also depends on the shape of the object, which is described by the moment of inertia. As robot is a system constrained by physical limitations, it will not experience infinite acceleration, but the motors will likely apply the maximum torque they are capable of during the brief moments at the beginning and the end of the motion. This increases wear and tear of the motor and other components, leading to the decreased lifespan of the robot. This issue can be mitigated by using a parabolic trajectory instead. Assuming the start velocity of zero and end velocity of zero, the parabolic trajectory will have a velocity profile that linearly increases until it reaches the half point of the trajectory and linearly decreases until it reaches zero again at the end of the trajectory. Consequently, the acceleration during first and second half of the movement will have much lower maximum value and will be constant, non-zero during majority of the motion. This leads to least wear and tear, but also slower movement. A balance between trajectory duration and maximum acceleration can be achieved by merging these two methods. Linear trajectories with parabolic blends have a linear part in the middle and paranolic at the start end end of the interpolation.

\bigskip \noindent
When moving between two points, it is not always clear if the robot will be able to move between then without collision. This is especially true with high degree of freedoom robotic arms as even if the path for the end effector is clear, other robot parts may be in collision due to the configuration of the robot. It is a difficult problem to address efficiently due to high dimentionality of the problem. Many modern robotics incorporate Rapidly-exploring Random Tree (RRT) \cite{lavalle1998rapidly} or RRT* \cite{karaman2011sampling} into their path planning algorithms to address this problem. RRT explores robot's configuration space, which is a high dimentional space that represent every possible configuration the robot can be in. C-Space can be divided into two sets, C-Free a space with valid robot configurations and C-Obs a space where robot configuration would be in a collision. 

\begin{gather*}
  C = C_{\text{free}} \cup C_{\text{obs}} \\
  C_{\text{free}} \cap C_{\text{obs}} = \emptyset
\end{gather*}

\noindent
RRT can find a collision free path between the two configurations in C-Free space if one exists. The algorithm builds a tree like structure by selecting a random point in a C-Free space, connecting it to the closest node in a tree (which the initial configuration during the first iteration), and growing a branch from that tree towards the random point until it or maximum distance is reached. That will be the new location for the node to be added into the tree if the path between the node and the closest points in the tree is obstacle free. Then a new random point in a C-Free space is selected and this process continues until a tree grows large enough so a path that connects the two points in configuration space is found. This method however does not yield shortest path, RRT* addresses this issue by doing additional processing before placing a node in a tree. Within a specified search radius around the new point, RRT* checks if the nodes can be reconnected in a way that yields a shorter path. It has been proved that when the time goes to infinity, RRT* will yield the shortest path between two points by continuously rewiring the tree. 

\bigskip \noindent
The linear interpolation between points with or without the use of parabolic blends, results in a robot moving in a straight line between the points. A more efficient and smooth path can be achieved by using splines. Splines ensure a smooth transition between path segments, avoids abrupt changes in velocity and acceration and minimizes jerk. An easy way to implement splines in a path with many points is to use B-splines. This approach is recommended only for the parts in the trajectory that do not need to go through the point exactly, as B-splines are just an approximation of the path, unlike interpolation methods that would go exactly through the point. B-splines are implemented by dividing each segment between points to the thirds and connecting a second third of the first segment to the first third of the second segment with a line. The center of this line will act as an anchor point for fitting a Bezier curve. The B-splines are amazing not only because they are easy to implement, but because they have $C^2$ continuity and local control. Local control means that moving a single point in the trajectory will affect only that local portion of the trajectory, keeping the rest of the trajectory unaffected. $C^2$ continuity (second-order continuity) ensures that the position, velocity and acceleration in the trajectory are smooth. $C^0$ position continuity ensures that the end of one segment matches the start of another. $C^1$ velocity continuity ensures that the first derivatives at the end of the one segment matches the start of another. And $C^2$ acceleration continuity ensures that the second derivative matches at the junction points between the segments. It is possible to achieve even higher order continuity, for example quintic splines can achieve a $C^3$ jerk continuity or even higher if higher degree polynomial is used to interpolate between the points. Quintic splines also go through the points unlike the B-splines. This could be desireable in cases where the points are defined manually. Quintic splines do come with several disadvantages, such as, lack of local control and computational complexity, so the choice of splines used would depend on the use case scenario.

\subsection{Neural Networks}
Neural network is a mathematical model inspired by biological neural network - the human brain. Neural networks are used in machine learning to achieve tasks that would be difficult or impossible by writing an algorithm for the task manually. The feedforward neural network \cite{lippmann1988introduction} was among the first types of the neural networks. The information in such a network only flows forward from input to the output, which is very suitable for classification tasks. Multilayer Perceptron (MLP) is a type of feedforward neural network that is divided into one dimentional layers, input layer, one or more hidden layers and an output layer. Each of these layers have one or more neurons. A neuron can be imagined as a place where a single, usually floating point value is stored. A simple and common approach to connect these layers is to use full connections, where each neuron is connected to every neuron in the previous layer. Modern networks can have millions and even billions of neurons, in such cases techniques where weak connections are cut are implemented to optimize the networks. The value that the neuron receives is calculated by multiplying the value of the previous neuron by the strength of the connection (weight) and addition of a bias. This process is repeated for all connections and summing up these values. As the neuron multiplication by a weight and addition of a bias is a linear function, the neurons need an additional activation function in order to learn non-linear patterns from the data. A common and popular activation function is sigmoid $f(x) = \frac{1}{1 + e^{-x}}$, which also clamps the neuron values between -1 and 1. In big networks however sigmoid adds a lot of additional computation, often ReLU \cite{nair2010rectified} is prefered. It is calculated simply as $f(x) = max(0, x)$. Turns out clamping negative values is enough to provide the desired nonlinearity to the network. ReLU however sometimes presents another problem, if the network is poorly initialized with a lot of negative weights and biases, the learning rate is too high or the data often leads negative neuron activations, the neurons stop learning. This is because after negative neuron value passes through the ReLU function it becomes zero. This is called a dying ReLU problem where too many neurons output zero for all inputs, effectively making them inactive and that prevents them from learning. Leaky ReLU addresses this problem, instead of clamping negative values to zero, they are multiplied by a small constant e.g. $\alpha=0.01$, this neurons from dying. For multi-class classification problem, the logits (raw outputs of the last layer before applying the activation function) are passed through a softmax function $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$, this outputs the probabilities of input beloging to each class, the highest probability is often choosen as a network prediction. The sum of probabilities of input belonging to each class is 1. The data for multi-class clasification is usually one-hot encoded, where the probability of it belonging to the true class is 1 and 0 for the rest. The loss for such problem is calulated using cross-entropy

\[
\mathcal{L} = - \sum_{i} y_i \log(\hat{y}_i)
\]

\noindent
where:  
\begin{itemize}
    \item \( y_i \) is the true label (usually one-hot encoded, meaning one class is labeled as 1, others as 0)
    \item \( \hat{y}_i \)  is the predicted probability for class i from softmax
\end{itemize}


\noindent
The cross-entropy measures the difference between two probability distributions, leading to stronger gradiens than using mean square error. For one-hot encoded dataset, the cross entropy simplifies to $\mathcal{L} = - \log(\hat{y}_{c})$ where $\hat{y}_c$ is the predicted probability of the true class. The goal of neural network training process is to minimize this loss. This is done through a process called backpropagation. The weights and biases need to be adjusted in a way that leads to lower loss. In order to know how the changes in weights and biases affect the loss a gradient can be used. During the backpropagation the gradiens are calculated for each weight and bias by the use of gradient chain rule. This way a simple way to minimize the loss is achieved, simply taking a step for each weight and bias in the negative gradient direction will result in lower loss until either a local or global minima is reached. Often when then network is big and there is a lot of data, it is unpractical to use all of the data for each pass as it is too resource intensive, often the data is split into smaller batches before being passed through the network. Another way a neural network training process is sped up is instead of using the vanilla gradient descent, a modern optimizer like adam is often employed. Adam (Adaptive Momentum Estimation) improves the gradient descent with two key ideas. Firstly, it incorporates momentum by using the mean of past gradients. This helps optimizer move in a constant direction and to reduce oscilations. Secondly, it optimizes the step size for each parameter individually based on past updates. This results in faster convergence, less sensitivity to noisy gradients (which can occur in mini-batch training) and less sensitivity to hyperparameter tuning.

\bigskip \noindent
Over the years, the feedforward neural network evolved into different architectures that are more suitable for specific tasks. Recurrent Neural Networks (RNNs) \cite{rumelhart1986learning} build upon a feedforward neural network by introducing loops in the network, a hidden state that carries information from the previous inputs. This makes RNNs ideal for tasks where order matters, such as language modeling or speech recognition. The hidden states however can not retain information over long period of time, for that an improvement was made with Long Short-Term Memory architecture. It uses cell state to carry information across time steps and gates that regulate what information should be store, what should be forgotten and what should be passed as an output. For image recognition and feature extraction tasks Convolutional Neural Networks (CNNs) \cite{krizhevsky2012imagenet} are often employed. Clasical image processing tasks, such as blurring, sharpening and edge detection are often achieved by sweeping a square 3x3 or bigger kernel throught the entire image and applying a convolution operation between kernel and each area in order to produce a new image pixel. Instead of using predefined kernel values, convolutional layers in CNNs learn these values during backpropogation. Image passed through convolution layers is called a feature map. A single image often produces many feature maps. Parameters like stride, padding, kernel size and pooling layers afftect the size of the feature map, but it is often smaller than the image itself, leading to a dense representation of the most important features. These feature maps then are flattened to one dimension and concatinated together before being passed through a feedforward neural network. CNNs themselves can only be around 15 layers deep before experiencing vanishing gradient problem. It has been found that deeper network can result in better feature extraction, a breaktrhough was achieved with residual neural network (ResNet) \cite{he2016deep} a type of CNN architecture that overcame the vanishing gradient problem. The ResNet layers can be 50 or even a 100 layers deep, making them the choice in many pre-trained backbones. For data compression, denoising and anomaly detection autoencoders are often used. They are often a fully connected networks with a bottleneck in the middle. This bottleneck is a lower-dimension space called laten space. It is the part of the network that captures the esential features of the input data.

\subsection{Reinforcement Learning}
Reinforcement learning (RL) is a subset of machine learning. There are three main types of machine learning, supervised learning, unsupervised learning and reinforcement learning. Supervised learning has labeled data, a model finds patterns that relate between labeled input-output data and once trained it can use those patterns to predict outcomes not yet known. Unsupervised learning has no labaled data or human feedback, instead it finds hidden structure in the data itself and can be used to cluster it. RL learns through trial and error by interacting with the environment, receiving feedback in the form of reward or punishment \ref{fig:reinforcement_learning_model}. It is ideal for tasks that require sequential decision making,  such as playing games, navigating self-driving cars or controlling robots.

  \centering
  \includegraphics[width=0.8\linewidth]{chapters/algorithms/images/Reinforcement learning model, agent - environemnt loop.png}
  \caption{Reinforcement learning model}
  \label{fig:reinforcement_learning_model}
\end{figure}

\noindent
In order to understand RL, it is important to understand the key concepts and the terminology:

\bigskip \noindent
Agent - the agent is the decision maker. In the context of a game it would be a player and in the context of this thesis it will be a robot arm.

\bigskip \noindent
Environment - it is a place in which the agent resides in. It encompasses everything that the agent perceives and acts upon.

\bigskip \noindent
Action - actions are choices available to the agent in a given state. The actions can be discrete, where the number of moves the agent can perform is finite, for example two actions could be open or close the robot gripper. The actions can also be continuous, they are often represented by a real number or a vector of real numbers. Robot's actions are often continuous, such as opening a gripper to a certain distance, or moving robot's joint to a certain angle. Reinforcement learning methods and approaches often differ depending if the actions are discrete or continuous. 

\bigskip \noindent
Action space - set of all valid actions in a given environment.

\bigskip \noindent
Reward - the feedback from the environment. A numerical value associated with how good the agent's action was. A positive value represents a reward and a negative value represents a punishment. It depends on the state, action and the next state of the environment $r_t = R(s_t, a_t, s_{t+1})$. Although frequently the reward dependance is simplified only to state-action pair or only the current state. The agent's goal is to maximize the cumulative reward. Designing a reward function that aligns with the desired behavior of the agent is a challenging task often requiring lots of trial and error by tuning and retraining the agent. Another difficulty are sparse rewards, for example the winner in the game of chess is only decided after the game has ended, it is difficult for the agent to know which of the moves led the agent to the victory or loss. Sparse rewards make the agent learn at a much slower rate leading to extensive training times.

\bigskip \noindent
Discount factor - $\gamma \in [0,1]$ is a parameter that discounts the future rewards. Often instead of weighting all of the rewards equally, more weight is given to short term rewards. Total cumulative reward over trajectory $\tau$ with discount factor is calculated as $R(\tau) = \sum_{t=0}^{\infty} \gamma^t r_t.
$. If the discount factor is high (e.g. 0.9 - 0.99) the agent will try to learn long-term strategies and if it is low, it will focus on quick gains.

\bigskip \noindent
Policy - policy is what defines the agent's strategy. It is a mapping between states and actions. There are two types of policies, deterministic and stohastic. Agent following a deterministic policy will always choose the same action given the same state. On the other hand, agent following a stohastic policy will have a probability distribution over the available actions.

\bigskip \noindent
Value function - represents an expected cumulative reward for a certain state or state-action pair if the agent were to act according to the same policy forever after. It shows how good a particular state or action is. State-value function $V(s)$: represents expected reward starting in a state s. Action-value function $Q(s, a)$: represents expected reward for taking action a in state s and following the policy thereafter. The action-value function is also known as Q-function.

\bigskip \noindent
Exploration vs. Exploitation - is a key challenge in RL on how to balance between exploration and exploitation. Exploitation means the agent chooses the best known action in order to maximize it's reward. Exploration means agent tries less known action in order to discover new, potentially better strategies. There are several exploration vs exploitation balancing strategies, one that is simple and well known is called $\epsilon - Greedy$. 

\begin{equation}
a =
\begin{cases} 
\text{random action}, & \text{with probability } \varepsilon \\
\arg\max_{a} Q(s, a), & \text{with probability } 1 - \varepsilon
\end{cases}
\end{equation}

\noindent
During beginning of the training $\epsilon \in [0,1]$ is initialized to a high value (e.g. 1), making the agent perform mostly random actions and as training continues epsilon decreases, making the robot prefer to exploit the policy.

\bigskip \noindent
On-Policy and Off-Polict learning. These are two ways the policies can be categorized. On-Policy learning refers to a process when the agent continuously updates the same policy it uses to interact with the environment. On-Policy learning often results in more stable, but much slower training compared to Off-Policy traing. Off-Policy training refers to a process when agent learns from experiences collected using different policy than the one it is currently improving. The agent saves a tuple $(s_t, a_t, r_t, s_{t+1}, done)$ to a replay buffer after each action it takes. during the training loop a number of random experiences is sampled from the replay buffer and used to update agent's policy. This parallelism of using many experiences at each iteration loop allow's the agent to learn quickly, but the learning may be less stable.

\bigskip \noindent
Many RL problems are modeled as Markov Decision Process (MDP). Problems that are modeled as MDP's assume a Markov Property that probability of transitioning to the next state $s_{t+1}$ depends only on the current state-action pair and not the past history of state-action pairs.

\begin{align}
P(s_{t+1} | s, a, s_{t-1}, a_{t-1}, s_{t-2}, a_{t-2}, \dots, s_0, a_0) = P(s_{t+1} | s, a)
\end{align}

\noindent
If the environment is only partially observable or it depends on the past states, problem can not be modeled as MDP. MDP framework models the environment as tuple $(S, A, P, R, \gamma)$:

\begin{itemize}
  \item \( S \) Set of all states
  \item \( A \) Set of all actions
  \item \( P(s_{t+1} | s, a) \) Probability of transitioning to the next state $s_{t+1}$ given state s and action a pair
  \item \(  R(s,a,s_{t+1})  \) Reward
  \item \( \gamma \) Discount factor
\end{itemize}

\noindent
This framework formalizes RL problems. The value functions for RL problem defined by MDP can be determined with the use of recursive formula called Bellman equation. The following are the Bellman equations for the On-Policy value functions:

\begin{align}
V^\pi(s) &= \mathbb{E}_\pi \left[ r_{t+1} + \gamma V^\pi(s_{t+1}) \right] \\
Q^\pi(s, a) &= \mathbb{E}_\pi \left[ r_{t+1} + \gamma Q^\pi(s_{t+1}, a_{t+1})\right]
\end{align}

\bigskip \noindent
These are used when evaluating a specific policy $\pi$. The actions are sampled from the policy $a \sim \pi(\cdot \mid s)$ and future states from the probability distribution $s_{t+1} \sim P(\cdot \mid s, a)$. The Bellman equations for the optimal policy are:

\begin{align}
V^*(s) &= \max_a \mathbb{E} \left[ r_{t+1} + \gamma V^*(s_{t+1}) \right] \\
Q^*(s, a) &= \mathbb{E} \left[ r_{t+1} + \gamma \max_{a_{t+1}} Q^*(s_{t+1}, a_{t+1}) \right]
\end{align}

\bigskip \noindent
These describe the best possible values if the agent always acts optimally. The $\max_a$ and $\max_{a_{t+1}}$ denote that the agent always picks the best action that maximizes the expected future rewards. From these equations value function update methods can be derived. The On-Policy method SARSA has the following Q-function update equation:

\begin{align}
Q(s_t, a_t) &\leftarrow Q(s_t, a_t) + \alpha \left( r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t) \right)
\end{align}

\noindent
$\alpha \in [0,1]$ is a learning rate. The Off-Policy method Q-Learning has the following Q-function update equation:

\begin{align}
Q(s_t, a_t) &\leftarrow Q(s_t, a_t) + \alpha \left( r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \right)
\end{align}

\subsection{Learning from Demonstration}
