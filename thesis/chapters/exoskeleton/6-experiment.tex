\section{Experiment}
The theoretical and practical force transmission of the rack and pinnion mechanism will differ due to losses in the system. In theory, without taking any losses into account the force produced by this mechanism is equal to the torque divided by the pitch radius Eq. \ref{eq:rack_and_pinnion_force}.

\begin{equation}
  F_{\text{theo}} = \frac{\tau_m}{r_p}
  \label{eq:rack_and_pinnion_force}
\end{equation}

\noindent
The pitch radius can be calculated using spur gear parameters Eq. \ref{eq:pitch_radius}

\begin{equation}
  r_{p} = \frac{m \cdot Z}{2} = 6mm = 0.006m
  \label{eq:pitch_radius}
\end{equation}

\noindent
In order to find practical force values an experiment has been devised, the picture of it can be seen in Fig. \ref{fig:experimental_setup_load_cell_connection_diagram}. The experiment is setup to measure the actual torque provided by the motor and force exerted by the pinnion. The dynamixel motor is controlled using current control. Positive current opens the grippr and negative current closes it. The current for this motor can be controlled in 2.69 [mA] intervals. The currect is converted to the torque using the Eq. \ref{eq:current}. The stall torque obtained from the motors data sheet is 4.1 [Nm] (at 12.0 [V], 2.3 [A]). The torque constant can be calculated as $k_t = \tau / I = 4.1 / 2.3 = 1.783 $. The force is measured using a 1kg load cell. The load cell was calibrated against a known weight object (a smartphone). As with all measurement devices there can be some measurement errors. The zero balance uncertainty is $\pm$0.1\% Rated Output (RO), the temperature effect on zero is $0.02\% \text{RO}/^\circ\text{C}$, the creep is $0.1\% \text{Full Scale (FS)}/5\text{min}$, repeatability error $0.03\% \text{FS}$ and deviation from an ideal linear response $0.05\% \text{FS}$.

\bigskip \noindent
The obtained values and theoretical values are plotted in Fig. \ref{fig:experiment_results}. To be able to read the plot left to right, instead of right to left as all of the values are negative, the x-axis and y-axis in the plot are inverted. Using this data the efficiency of the exoskeleton can be calculated Eq. \ref{eq:efficiency}. The efficiency was calculated as an average over the values starting from the point where the exoskeleton exhibits non-zero force Eq. \ref{eq:efficiency_average}.

\begin{equation}
  \eta = \frac{F_{\text{exp}}}{F_{\text{theo}}} \times 100\%
  \label{eq:efficiency}
\end{equation}

\begin{equation}
  \eta_{\text{avg}} = \frac{1}{n} \sum_{i=6}^{n} \left( \frac{F_{\text{exp},i}}{F_{\text{theo},i}} \times 100\% \right) = 56.93\%
  \label{eq:efficiency_average}
\end{equation}
